# Auto Click

Flutter로 만든 자동 클릭 앱입니다. 지점 탭, 영역 랜덤 탭, 길게 누르기, 스와이프, 대기를 조합해 **루틴**을 만들고, **프리셋**으로 저장해 반복 실행합니다.

## 플랫폼별 지원 범위

| 기능 | Android | iOS | Web |
| --- | :---: | :---: | :---: |
| 루틴 / 프리셋 작성 · 저장 · 가져오기 · 내보내기 | ✅ | ✅ | ✅ |
| 테스트 패드 (앱 내부 터치 주입으로 루틴 검증) | ✅ | ✅ | ✅ |
| **다른 앱 위에서 자동 클릭** | ✅ (접근성 권한) | ❌ | ❌ |
| 플로팅 패널 (다른 앱 위에서 위치 지정 · 실행 · 정지) | ✅ | ❌ | ❌ |

> **iOS · 웹이 안 되는 이유**: iOS는 다른 앱에 터치를 보내는 공개 API가 없습니다(App Store 정책으로도 금지). 브라우저는 보안 샌드박스 때문에 다른 탭이나 앱을 조작할 수 없습니다. 그래서 이 두 플랫폼에서는 루틴 작성과 프리셋 관리, 그리고 앱 내부 테스트 패드 실행만 할 수 있습니다.

## 주요 기능

- **단계 종류**: 탭 · 더블 탭 · 길게 누르기 · 영역 랜덤 탭 · 스와이프 · 대기
- **루틴 설정**: 루프 횟수(0 = 무한), 루프 간격, 시작 지연, 최대 실행 시간, 단계별 반복 횟수
- **사람처럼 보이게**: 좌표 흔들기(±px), 랜덤 추가 대기(ms)
- **좌표 지정**
  - Android: 대상 앱 위에서 플로팅 패널의 `추가 → 탭 / 길게 / 영역 / 스와이프 / 대기`로 바로 기록. 길게 누른 시간과 스와이프 속도까지 기록됩니다.
  - 앱 안: 전체 화면 위치 지정기(탭, 드래그로 영역 · 스와이프 지정, 10% 격자 표시)
- **화면 위 마커 편집 (Android)**: 정지 상태에서 번호 마커를 누르면 그 단계의 클릭 간격 · 반복 · 누르는 시간 · 순서 · 삭제 카드가 열립니다. 마커를 끌면 위치가 바뀌고, 영역은 오른쪽 아래 점을 끌어 크기를 조절합니다.
- **패널 안 설정 · 저장 (Android)**: 패널의 `설정`에서 프리셋 전환, 새 루틴, 이름 변경, 다른 이름으로 저장, 루프 · 간격 · 랜덤 설정, 모든 단계 간격 일괄 변경을 할 수 있습니다. `저장`을 누르면 바로 저장되며, 변경 사항은 자동으로도 저장됩니다. 앱이 꺼져 있어도 유지됩니다.
- **프리셋**: 복제, 템플릿(연타 / 영역 랜덤 / 피드 넘기기 / 조합 예시), JSON 클립보드 내보내기 · 가져오기
- **처음 쓰는 사람을 위한 안내**: 첫 실행 가이드, 홈의 3단계 "시작 가이드" 체크리스트, 언제든 열 수 있는 `?` 사용 방법, 패널을 처음 열면 나오는 사용법 카드
- **권한 바로가기**: "권한 설정하기"를 누르면 Auto Click 접근성 항목으로 바로 이동합니다. 기기가 허용하지 않으면 접근성 목록에서 해당 항목을 강조하고, 그것도 안 되면 앱 정보 화면을 엽니다.

## Android 사용법

1. 앱 실행 → 홈의 시작 가이드에서 **권한 설정하기** → Auto Click 켜기
   - "제한된 설정" 때문에 켜지지 않으면(APK 직접 설치 시): **앱 정보** → 오른쪽 위 ⋮ → **제한된 설정 허용**을 한 뒤 다시 켭니다.
2. **플로팅 패널 열기**를 누르고, 자동으로 누를 앱을 엽니다.
3. 패널의 **추가 → 탭**을 누르고, 누를 곳을 터치합니다. 번호 마커가 생깁니다.
4. **번호 마커를 누르면** 클릭 간격(주기) · 반복 횟수 등을 설정할 수 있습니다. 마커를 끌면 위치가 옮겨집니다.
5. **실행**으로 시작하고 **정지**로 멈춥니다. 실행 중에는 마커가 터치를 막지 않습니다.
6. **저장**을 누르면 프리셋에 저장됩니다. 다음부터는 홈 목록에서 ▶로 바로 실행할 수 있습니다.

| 패널 버튼 | 하는 일 |
| --- | --- |
| 실행 / 정지 | 루틴을 순서대로 반복합니다 |
| 추가 | 탭 · 길게 · 영역 · 스와이프 · 대기 · 되돌리기 |
| 설정 | 프리셋 전환 · 새 루틴 · 이름 변경 · 반복/랜덤 설정 · 단계 목록 |
| 저장 | 지금 루틴을 저장합니다 |
| 마커 | 번호 마커를 보이거나 숨깁니다 |
| 앱 | Auto Click 앱으로 돌아갑니다 |
| 맨 위 손잡이 | 끌면 패널이 이동하고, 누르면 접히거나 펼쳐집니다 |

필요한 권한은 **접근성 서비스 하나**뿐입니다. 오버레이는 `TYPE_ACCESSIBILITY_OVERLAY`를 쓰므로 "다른 앱 위에 표시" 권한이 따로 필요하지 않습니다. 서비스는 화면 내용을 읽지 않고(`canRetrieveWindowContent=false`) `dispatchGesture`로 터치만 보냅니다.

## 실행 · 빌드

```bash
flutter pub get
flutter run -d <android-device>   # Android
flutter run -d chrome             # Web
flutter run -d <ios-device>       # iOS (macOS + Xcode 필요)

flutter build apk --release
flutter build web
flutter build ios
```

> Windows에서 프로젝트 경로가 길면 셰이더 컴파일 단계에서 `Could not write file` 오류가 날 수 있습니다(MAX_PATH 260자 제한). 짧은 경로(예: `C:\src\auto_click`)로 옮겨서 빌드하세요.

## 프리셋 JSON 형식

좌표는 화면 크기 대비 0 ~ 1 비율이라 해상도가 다른 기기에서도 같은 프리셋을 쓸 수 있습니다. 화면 방향은 기록할 때와 같아야 합니다.

```json
{
  "name": "피드 넘기기",
  "loopCount": 0,
  "loopIntervalMs": 0,
  "startDelayMs": 1500,
  "maxRunSeconds": 0,
  "randomOffsetPx": 0,
  "randomDelayMs": 0,
  "steps": [
    { "type": "swipe", "x": 0.5, "y": 0.7, "x2": 0.5, "y2": 0.3, "durationMs": 300, "delayAfterMs": 0, "repeat": 1 },
    { "type": "wait", "durationMs": 3000 }
  ]
}
```

`type`: `tap` · `doubleTap` · `longPress` · `areaTap`(x,y = 좌상단, x2,y2 = 우하단) · `swipe` · `wait`
